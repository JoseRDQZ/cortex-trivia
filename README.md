Project Name:
Computer Science: Cortex - A Turn-Based Trivia Website

Project Description:
This project will be a web-based multiplayer trivia game where 4–8 players join a shared session, select a topic and difficulty level, and answer timed questions to earn points. Points will be awarded based on correctness and response speed, and each game concludes with a podium ranking of the top three. Trivia questions and gameplay results are stored in a database, enabling basic analytics such as accuracy and response-time trends by topic and difficulty. The platform will support multiple trivia categories, featuring extensive question banks to ensure varied gameplay.

Single / Multiplayer Modes: The player can choose to play if play for themselves or with other people
Free for All / Team Modes: The player can choose whether to play by themselves against other players or in a team against other players
4 – 8 players: the limit of players that our website accounts for so far.
Scalable difficulty: Random difficulty, high risk, high reward. The harder the question and the faster it is answered correctly, the more points it awards, but also if you get it wrong, by the value of the question’s points
Top 3 Podium (team or individual podium): Whoever scores the highest gets up in the top 3 
Database Analysis: It is like performances report for the player/team
